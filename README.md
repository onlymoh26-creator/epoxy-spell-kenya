# Epoxy Spell Kenya website

A mobile-first static website starter for Epoxy Spell Kenya, built with separate HTML, CSS and JavaScript files.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive design and styling
- `app.js` — mobile menu, gallery lightbox and WhatsApp quote form

## Before publishing
1. Replace the temporary `ES` text mark in `index.html` with your official logo. You can save your logo as `images/epoxy-spell-logo.png` and update the brand markup to use an image.
2. Review the gallery and service images. Current images are remote inspiration images and are not represented as completed Epoxy Spell Kenya projects. Replace them with your own project photographs when available.
3. Check all business details and the WhatsApp number.
4. Open `index.html` in a browser and test the quotation form on a phone.

## Publish using GitHub Pages
1. Create a **new, separate GitHub repository**, for example `epoxy-spell-kenya`.
2. Upload `index.html`, `styles.css`, `app.js` and this README into the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The temporary address will look like `https://YOUR-USERNAME.github.io/epoxy-spell-kenya/`.
6. A custom domain can be connected later after you purchase one.

This project is separate. Do not upload these files over the Smart Drive or Mjengo repositories.
